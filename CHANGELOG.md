# Changelog

Todos los cambios importantes de KlinCAD se documentarán en este archivo.

El formato sigue una estructura inspirada en Keep a Changelog.

## [Unreleased]

### Añadido

- Nueva arquitectura modular del proyecto.
- Separación de editor, elementos gráficos, interfaz y servicios.
- Sistema de historial independiente.
- Servicios independientes para proyectos y exportación.
- Sistema de configuración persistente.
- Pruebas automatizadas iniciales.

### Mejorado

- Organización del código para facilitar mantenimiento y desarrollo.
- Separación de responsabilidades respecto al archivo monolítico original.

## [0.1.0] - 2026-09-23

### Añadido

- Editor gráfico de circuitos KlinCAD.
- Componentes electrónicos.
- Pistas interactivas.
- Nodos y mallas.
- Sistema de cuadrícula.
- Capas.
- DRC para conexiones.
- Visor isométrico 2.5D.
- Exportación PNG y PDF.
- Guardado y apertura de proyectos.
- Calculadora electrónica.
- Interfaz ES/EN.
